# Repository instructions

## Commit attribution

Any AI agent that creates or helps create a commit must identify itself by adding its own `Co-authored-by` trailer to the commit message.

Use this format, replacing the name and email with the AI agent's identity:

```text
Co-authored-by: AI Agent Name <agent@example.com>
```

Each participating AI agent must add a separate trailer. Human authorship and existing attribution must be preserved.
